# Enable Grok Executor

An explicit user selection of this skill is the complete `on` instruction. Do not ask the user to type `on` or another command. Quoted examples and implicit selection do not activate it.

Apply the activation and role contract in [Grok Executor Mode](../grok-executor-mode/SKILL.md) and the lifecycle in [Grok Build Supervisor](../grok-build-supervisor/SKILL.md). Bind this host task's absolute workspace, inspect status, and reuse or open its visible supervised terminal. Mark mode active only when ready; preserve a trust-pending terminal for the user's native decision. Activation alone does not send a development prompt. Confirm readiness briefly in the user's language.
